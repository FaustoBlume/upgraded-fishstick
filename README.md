# MySoli

Aplicación creada por Tomás Vivas, Fausto Blume y José Gabriel Donadello, para la administración de tickets y búsquedas laborales.

(MySoli utiliza [Angular CLI](https://github.com/angular/angular-cli) v19.2.5 y [Google Firebase](https://firebase.google.com/?hl=es()) v19.0.0)

# Link: https://mysoli-cb4e8.web.app/


# Ejecución local (si usted tiene instalado Angular)

- Clonarse este repo
- En la carpeta principal, abrir consola de comandos de Windows (CMD, Windows PowerShell)
- Ejecutar `ng serve`. Esto ejecuta el programa. Esperar a que termine la ejecución.
- Al terminar la ejecución, entrar desde un navegador web a `http://localhost:4200/`. Si el puerto 4200 está en uso, verifique en la pantalla de compilación qué otro puerto es sobre el que se está ejecutando, reemplace 4200 por el mismo.
